# ULTRA CATZT LANDING ⚡

Full 1:1 Pixel-Perfect Bonhomme Paris Web Engine & Design Duplicate for Catzt Office.

## 🚀 Overview
- **Engine**: Bonhomme Paris custom JavaScript bundle (`main-3s9LLrbV.js`)
- **SPA Routing**: Barba.js transition lifecycle
- **Animations**: GSAP (Draggable, Flip, Inertia, ScrollTrigger, ScrollTo, SplitText)
- **3D Graphics**: Three.js WebGL interactive carousel & rotor
- **Layout System**: 48-Column Responsive CSS Subgrid
- **Pages**: 15 complete routes fully duplicated with local high-resolution assets

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start development server (Port 7700)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
